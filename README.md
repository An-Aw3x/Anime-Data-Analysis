# Anime Data Analysis

A data analysis project exploring anime datasets from Kaggle. This project was created as part of a college class assignment to demonstrate data analysis and visualization techniques using Python and Jupyter notebooks.

## 📊 About the Project

This repository contains a comprehensive analysis of anime data, including trends, patterns, and insights derived from the dataset. The analysis is performed using Python in a Jupyter notebook with various data visualization libraries.

## 🚀 Getting Started

### Prerequisites

- Python 3.7 or higher
- pip (Python package installer)
- Jupyter Notebook

### Installation

1. Clone the repository:
```bash
git clone https://github.com/An-Aw3x/Anime-Data-Analysis.git
cd Anime-Data-Analysis
```

2. Install the required Python packages:
```bash
pip install -r requirements.txt
```

### Usage

1. Launch Jupyter Notebook:
```bash
jupyter notebook
```

2. Open the analysis notebook from the Jupyter interface in your browser

3. Run the cells in order to see the analysis and visualizations
